## 🛠️ Como Executar os Programas

Se você quiser clonar este repositório e testar os códigos na sua máquina, siga os passos abaixo no terminal:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/devkatiareis/c-programming
   ```

2. **Acesse a pasta do programa desejado:**
   ```bash
   cd c-programming/01-logica-de-programacao
   ```

3. **Compile o código fonte (Requer GCC instalado):**
   ```bash
   gcc calculo_media.c -o calculo_media
   ```

4. **Execute o programa:**
   - **No Windows:** `calculo_media.exe`
   - **No Linux/Mac:** `./calculo_media`
